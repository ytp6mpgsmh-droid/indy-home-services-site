# Build checklist: first to last

Only work on the next unchecked step. Who does it: **You** · **Claude** (this project: research and writing) · **Chrome** (Claude in Chrome, clicking in WordPress).

## Phase 1: Set up the basics (week 1)
- [ ] 1. **You:** Confirm which WordPress you have (WordPress.com or another host) and which plan. Check that it allows plugins; if not, upgrade or switch hosts.
- [ ] 2. **You:** Register IndyFoundationGuide.com and connect it to WordPress.
- [ ] 3. **You:** Turn on automatic backups.
- [ ] 4. **You:** Turn on "Coming soon" mode so nobody sees the half-built site.
- [ ] 5. **You + Chrome:** Pick the theme (newest "Twenty Twenty-…" default, or Kadence/GeneratePress) in light mode, then apply our colors and fonts.
- [ ] 6. **Chrome:** Settings → Permalinks → Custom Structure `/news/%postname%/` (pages keep short addresses like /costs; news posts get /news/post-name). Install an SEO plugin (Yoast or Rank Math). Set the site title and make the homepage a static page.
- [ ] 7. **You:** Book a one-hour attorney call. The questions are in the plan PDF, plus the disclosure and form-consent wording.

## Phase 2: Build the skeleton (week 2)
- [ ] 8. **Chrome:** Create every page as an empty draft with the right URL and parent page (full list in `page-list.md`).
- [ ] 9. **Chrome:** Build the main menu and the footer.
- [ ] 10. **You + Chrome:** Connect Google Search Console and Google Analytics (the Site Kit plugin does both).

## Phase 3: Trust pages (week 2–3)
- [ ] 11. **Claude:** Draft About, How We Rank, Disclosures, Contact and Privacy Policy.
- [ ] 12. **You:** Add your real name and photo, then send Disclosures and Privacy Policy to the attorney.
- [ ] 13. **Chrome:** Place the approved text on the pages.

## Phase 4: Content, easiest SEO wins first (weeks 3–8)
For each page: Claude drafts it, you read and fact-check it, Chrome places it and sets the SEO title and description.
- [ ] 14. Basement Waterproofing Cost guide
- [ ] 15. Foundation Repair Cost guide
- [ ] 16. Bowing Basement Walls and Sump Pump Installation guides
- [ ] 17. The 6 main service guides
- [ ] 18. The 8 problem pages
- [ ] 19. **You + Claude:** Verify each contractor's open questions, then publish the contractor profiles, the directory and the 6 "Best in Indianapolis" pages.
- [ ] 20. Costs summary page, then the homepage (last, because it links to everything)

## Phase 5: Launch (week 8–9)
- [ ] 21. **You + Chrome:** Final check: no [placeholders] or [CHECK] left; one H1 per page; every page looks right on a phone; homepage scores well in PageSpeed Insights.
- [ ] 22. **You:** Turn off "Coming soon," publish, and submit the sitemap in Search Console.

## Phase 6: After launch (months 1–6)
- [ ] 23. **You:** Get the first links: email each listed contractor, contact home inspectors and realtors, and answer questions helpfully on r/indianapolis and local Facebook groups.
- [ ] 24. **Claude + You:** Publish 1–2 news posts a month, and refresh the contractor data and cost guides every quarter.
- [ ] 25. **Once visitors arrive:** Add the lead form (with attorney-approved consent wording), the Google Sheet and the automations.
- [ ] 26. **You:** Offer contractors 3–5 free trial leads, then per-lead pricing. Add CallRail when the first contractor pays.
- [ ] 27. **Month 6:** Check whether the cost guides are on Google's first page and visits are growing, then plan the next pages.
